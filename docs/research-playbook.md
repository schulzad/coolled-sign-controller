# Research playbook

1. Photograph and label the physical panel and controller board.
2. Run a name-filtered scan, then an all-device scan if necessary.
3. Inspect GATT without writes and preserve the JSON result.
4. Record a connect-only application session twice.
5. Record one-action captures with one changed variable at a time.
6. Normalize traces by direction, handle/UUID, payload, and relative time.
7. Promote only isolated fields into an experimental profile.
8. Dry-run packet generation and compare it byte-for-byte with captures.
9. Execute only a low-risk verified command with explicit operator approval.
10. Record visible behavior and attach the profile revision to the result.

# Panel recordings

Real captures of the physical panel playing the gallery clips, shown beside the
codec's render in the top-level README.

The `*.recording.png` files here are placeholders ("recording coming soon"
tiles). Replace each with your own capture of the panel, keeping the base name so
the README picks it up — e.g. drop in `nian.recording.png`, or an animated
`nian.recording.gif` and point the README `<img src>` at it.

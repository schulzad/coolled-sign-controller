# Panel recordings

Real captures of the physical panel playing the gallery clips, shown beside the
codec's render in the top-level README.

Each is a phone capture cropped to the panel and scaled to 686 px wide. The
handheld Gengar temporal GIFs are aligned frame by frame against the sign on the
wall below the panel and share one 64-colour palette, which keeps them near
1.3 MB. To add a capture, name it after its gallery clip (for example
`matrix-rain.recording.gif`) and point the README `<img src>` at it.
